# Tradeoffs

## EF Core vs Raw SQL

Chosen: EF Core

Reason:
- Faster development
- Easier maintenance

Tradeoff:
- Less control over query optimization

---

## Batch vs Real-Time

Chosen: Batch processing

Reason:
- API limitations
- Cost efficiency

---

## Monolith vs Microservices

Chosen: Monolith

Reason:
- Lower complexity
- Easier to manage

---

## Rule-Based vs ML

Chosen: Rule-based automation

Reason:
- Transparency
- Control
